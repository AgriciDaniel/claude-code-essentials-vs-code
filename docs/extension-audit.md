# Original 26-extension bundle audit

Checked 2026-09-08 against each publisher's live Visual Studio Marketplace listing, Microsoft documentation, and the Marketplace public gallery query API. Scope: the 26 IDs in the original `scripts/install-extensions.ps1` / `.sh`; no extensions were installed or executed. This is a relevance and maintenance review, **not a package source-code or vulnerability audit**. Listing availability, a recent update, and publisher verification do not establish safety.

## Material corrections for viewers

1. **The bundle is optional, not a Claude Code prerequisite.** Python, Prisma, containers, notebooks, and API clients serve different projects. Offer explicit selections instead of silently installing all 26. Python itself brings additional extensions, so “26 extensions” is a direct-selection count, not a guaranteed final inventory.
2. **TypeScript Nightly is unsuitable as a beginner default.** Its publisher explicitly says ordinary JavaScript/TypeScript editing needs no extra extension and warns about stability. Keep it out of the routine bundle. [Publisher warning](https://marketplace.visualstudio.com/items?itemName=ms-vscode.vscode-typescript-next).
3. **Docker's old ID is a wrapper, not a failed package.** `ms-azuretools.vscode-docker` now installs a Docker Extension Pack whose current member is Container Tools. Prefer the explicit `ms-azuretools.vscode-containers` ID for a new optional selection; do not automatically uninstall a user's existing pack. [Migration notice](https://marketplace.visualstudio.com/items?itemName=ms-azuretools.vscode-docker), [current Microsoft guidance](https://code.visualstudio.com/docs/containers/overview).
4. **Copilot has a documented migration.** Microsoft announced retirement of the separate `GitHub.copilot` extension in favor of `GitHub.copilot-chat`. The old listing and gallery record still resolve during this audit, so removal or installation failure is **not verified**. Follow current Copilot setup rather than promising the old pair is required. [Microsoft announcement](https://code.visualstudio.com/blogs/2025/11/04/openSourceAIEditorSecondMilestone), [setup](https://code.visualstudio.com/docs/setup/copilot).
5. **Cline is a separate product.** `saoudrizwan.claude-dev` is the valid Cline ID; it is not Anthropic's Claude Code extension. Installing Claude Code, Copilot, and Cline together is not necessary. Each should have its own consent, account/provider setup, data-handling review, and cost expectations. [Cline listing](https://marketplace.visualstudio.com/items?itemName=saoudrizwan.claude-dev).
6. **WSL is conditional on a Windows-host development workflow.** Do not include it by default for native macOS/Linux. Installing its extension does not install or initialize a WSL distribution. [WSL listing](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-wsl).

## Security and installer implications

VS Code states that extensions share the editor's permissions, including file, process, and network access. Trust in a pack also involves its dependencies. CLI installation does not automatically mark the publisher trusted. Keep publisher prompts and Workspace Trust intact; a named VS Code profile is a configuration boundary, **not a security sandbox**. [Extension runtime security](https://code.visualstudio.com/docs/configure/extensions/extension-runtime-security).

An installer should show exact selected IDs, skip already-installed selections, preserve failures and return a failing status for unsuccessful installs. Do not suppress stderr and then claim the entire list succeeded, as the original PowerShell loop did. Do not use `--force` routinely. Let VS Code resolve compatible releases, and expose the resulting inventory separately from the number requested. Installing a current extension is not a reproducible version lock: VS Code may update it later.

The bundle should not silently change editor settings, trust policies, agent approvals, account credentials, model providers, MCP servers, WSL distributions, Docker engines, interpreters, or project dependencies. Consent to install an extension does not authorize those separate actions.

## Metadata method and limits

Read-only metadata query: `POST https://marketplace.visualstudio.com/_apis/public/gallery/extensionquery`, request header `Accept: application/json;api-version=7.2-preview.1`, JSON `filters[0].criteria` containing one `{ "filterType": 7, "value": "publisher.extension" }` per original ID, and `flags: 914`. The response returned all 26 records. Dates above are each record's `lastUpdated` converted to a UTC calendar date. The API POST queries catalog data; it does not publish or alter extensions.

The listing URLs in each row supply publisher descriptions and version-history access. Source availability and metadata were verified from Windows using read-only requests. There were **no install, activation, editor, Windows integration, Linux, or macOS compatibility tests** in this audit. No vulnerability database sweep, VSIX inspection, dependency-tree audit, or publisher identity investigation was performed. Those are outside this bounded setup refresh; do not describe any listed package as audited safe.
