# Resources to evaluate

The old ranked “Top 30” list and frozen star counts were not a maintenance or
security guarantee. This setup no longer promotes third-party framework
installers as prerequisites. Start with the primary references:

- [Claude quickstart](https://code.claude.com/docs/en/quickstart)
- [Installation and updates](https://code.claude.com/docs/en/setup)
- [Official VS Code integration](https://code.claude.com/docs/en/vs-code)
- [Skills](https://code.claude.com/docs/en/skills)
- [Subagents](https://code.claude.com/docs/en/sub-agents)
- [MCP](https://code.claude.com/docs/en/mcp)
- [Plugins](https://code.claude.com/docs/en/plugins)
- [Hooks](https://code.claude.com/docs/en/hooks)
- [VS Code extension security](https://code.visualstudio.com/docs/configure/extensions/extension-runtime-security)

Local [templates](../templates/) are optional starting points. See
[configuration guidance](claude-code-guide.md) before copying them.

If evaluating a community framework independently, inspect its current release,
maintainer activity, install script, permissions, version pinning and uninstall
path. A GitHub star count does not establish safety, necessity or compatibility.
